# BEYOND EARTH

Updated educational space-exploration website.

## What changed
- Integrated 100 additional mission records from the supplied LANZADO PDF into the existing archive.
- Kept the original featured missions and merged the PDF details into the existing Voyager and Cassini entries to avoid duplicate cards.
- Added archive filters for destination, mission type, and status.
- Expanded search across mission names, destinations, summaries, history, and agencies.
- Added a favorites-only view and a reset control.
- Mission detail windows now show launch/status information and identify PDF-derived records.
- Retained the existing instrument explorer, mission builder, and educational simulator.

## Run locally
1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local address printed by Vite.

The mission-builder save and favorites features use this browser's local storage. Simulator outputs are educational illustrations, not real mission calculations.
